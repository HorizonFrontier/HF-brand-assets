# HFR Brand Assets & Identity Repository

**Classification:** Internal / Restricted  
**Owner:** Brand Management  
**Compliance:** ISO 9001:2015 / HFR-IMS  

## 1. Overview
This repository serves as the central source of truth for Horizon Frontier (HFR) corporate identity assets. It ensures consistency, technical rigor, and version control across all digital and print communications.

## 2. Directory Structure
*   **/assets**: Host for static images (Logos, Icons). accessible via GitHub Pages.
*   **/email-signatures**: Standardized HTML templates for Outlook/Zoho.
*   **/guidelines**: Official color codes, typography, and tone-of-voice rules.
*   **/templates**: Standardized document formats (Word, Excel).

## 3. Usage & Governance
*   **Do not** download logos to your desktop and re-upload them elsewhere. Always link to the "Master Assets" via the GitHub Pages URL.
*   **Do not** modify the color hex codes in the HTML signatures.
*   All changes must go through a Pull Request review process by the Brand Manager.

## 4. GitHub Pages URL
Assets in this repository are served publicly at:  
`https://HorizonFrontier.github.io/hfr-brand-assets/`
